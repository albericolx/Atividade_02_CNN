# Atividade 02 - CNNs

**Descrição**: Esta pasta contém a implementação da atividade 02 focada em Redes Neurais Convolucionais (CNNs). O objetivo é demonstrar domínio sobre arquiteturas CNN, implementando um modelo de um artigo científico de 2023 em diante, e avaliando o impacto de três modificações arquiteturais sucessivas.

## Estrutura
- `code/`: Contém os notebooks e scripts Python para treinamento e inferência da CNN.
- `papers/`: Contém os arquivos LaTeX sincronizados com o Overleaf para a escrita do relatório técnico/artigo.
- `core/`: Utilitários e scripts adicionais (se necessário).
